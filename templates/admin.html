Settings backup and restore

Download a versioned backup bundle from the interface, then restore it on a new install or after an upgrade. The import path restores supported settings into the current schema instead of blindly replacing files, so it is more resilient across package versions.
Download backup
How restore works Backups include profile, group, strobe preset, light, detector, bridge, and web settings. They may also contain secrets such as passwords and bridge keys, so store them carefully. On import, the package keeps using the current code and normalizes the restored settings into the current config format.

Practical detector tips Onset fires only when the detector itself believes a beat hit happened. Phase locked builds a shared beat grid once tempo is known, which helps multiple bulbs stay on the same rhythm. Gated and adaptive are usually better for lounge, chill, jazz and cuban because they stop the grid from punching hard during quiet passages.

Audio and timing basics

CPU vs detector quality Lower sample rates can cut CPU a lot, but on some material they also hurt beat detection. Calibration mode is intentionally a debug tool and its CPU cost should not be treated as final profile runtime cost.

Global render defaults

Render mode guide Calibration is only for timing tests. Color only keeps motion and color changes while minimizing beat pulse. Pulse only strips color motion back to brightness pulses. Hybrid is the intended normal mode because it blends both layers.

Profiles and light groups

Profiles now carry the room style. Inside a profile you can split lights into groups such as ambient, accent or background, each with different brightness, pulse and color behavior while still sharing one timing model.
Built-ins are editable here, but it is safer to copy one into a custom profile before changing it heavily.
Profile defaults These values are the room-wide defaults for this profile. Groups inherit them and only need to override what should differ. Put the main room palette here, then use group palettes only when one set of lights should intentionally look different.
Light groups
One light should belong to one group inside the active profile. Use groups to keep some bulbs soft and ambient while others pulse harder.
Group design tip Use groups for behavior. For a slow ceiling chase, split the 20 spots into 4 groups, set those groups to beat_chase, set Change/chase every to e.g. 4, and set Beat chase off % to 0 for true off or e.g. 10–20 for a dim glow. Each chase group stays steadily on for its own Change/chase every value and holds one color until its next activation. Groups not set to beat_chase keep rendering normally.

Strobe presets

Create multiple named strobe buttons for the control page. Beat-locked mode keeps flashes aligned to BPM as well as possible within bulb timing limits.
Strobe warning True hard ON/OFF strobe is still limited by Zigbee/Hue bulb behavior. Beat-locked mode is useful for experiments, but pulse-only or hybrid profiles usually give smoother real-world results.

Validation and raw JSON

Validation runs live while you edit. It is fine to leave some lights unused. The main thing to avoid is assigning the same light to multiple groups in the same profile.
Color model Color styling now belongs in profiles and profile light groups. Per-light allowed_colors is only a hard safety limit. If a light has no per-light limit, the active group palette wins, then the profile palette, then an internal fallback palette only as a last resort.
